# Contributing

Thanks for considering contributing to WisdomVault AI. A few guidelines:

- Fork the repository and create a topic branch for your change.
- Run tests and linters locally before opening a PR:
  - pytest -q
  - ruff check .
  - mypy
- Keep changes small and focused. Add tests for bug fixes and new features.
- Follow the project's formatting (black, ruff, isort) and typing policies.

When opening a PR, describe the motivation and include screenshots or examples when relevant.
